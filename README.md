# Workspace AI

An extensible AI Workspace Platform built with Java and Spring Boot.

The goal is not to build another chatbot, but a platform capable of hosting multiple AI workspaces such as:

- Developer Workspace
- Document Workspace
- Travel Workspace
- Finance Workspace

The project focuses on production-grade AI engineering including:

- Spring AI
- MCP
- RAG
- Tool Calling
- Event-driven Architecture
- Observability
- Kubernetes
- AWS
